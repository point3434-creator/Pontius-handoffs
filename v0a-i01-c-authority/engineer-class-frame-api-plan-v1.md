## Proposed state and helper changes

| Change | Concrete representation and owner |
| --- | --- |
| Lexical origin | Adopt A's immutable _LexicalCellId(serial) and _CellIdentity = int or lexical token. Only ExecutionState construction with local_names mints a lexical token. Existing bindings, callable record cells, and authority cell store carry it. No second ownership map. |
| Per-callable scope | Retain the already computed construction-time lexical scope in each AuthorityRecord.value.callable_scope. Complete scoped free/nonlocal forwarding discovery replaces Load-only discovery once at construction, including Store/Del and implicit AugAssign read without promising new arithmetic support. |
| Capture API | _captured_bindings(value, live_state) returns the ordinary full capture view, including unproved alternatives and missing obligations; _proved_nonlocal_destination(name, scope, binding_view, live_state) grants guard relief only for a complete own-nonlocal/not-global route with all lexical tokens present in the live store. |
| Class frame | One immutable _ClassFrame contains a frozen outer continuation snapshot, its name/binding skeleton, the enclosing nonclass activation's binding view, and parent frame. The snapshot owns saved outer observed/results tables. It is not a live cell-value source. Resolver _class_frame replaces the immediate-method-only _definition_enclosing_values override. |
| Effect projection | _refresh_bound_projection(destination) merges current values of its existing binding tuples into raw name slots. _project_class_exit(frame, successor) forks the saved outer continuation, adopts successor objects/cells, restores the saved outer observed/results tables, then refreshes its outer bindings. No semantic setter runs during hydration. |
| Class execution | _flow_class_statement(ClassDef, state) owns header, class-body, and completion phases. A bounded _flow_class_body driver advances each immediate item via existing _flow_statement, accumulates nonnormal successors, coalesces with existing rules, and stops when normal is empty. |
| Historical callable | Add _ReviewFlow.callable_values_by_call with the already merged callable value from _snapshot_call. It pairs with values_by_call. Existing callables_by_call stores a string, not the capture-bearing callable; observed cannot substitute because AuthorityState.join clears it. |
| Shared entry construction | Factor capture hydration into a private helper usable by _call_environment and recursive _review_body entry. It accepts the retained callable plus matching historical state, projects only recorded incoming bindings, and raw-hydrates them. It never evaluates an AST or performs a call. |

The immutable frame freezes structure once per entered class. If implemented as an ExecutionState snapshot rather than separate primitive snapshots, its mutating APIs must remain inaccessible to the class path: never call frame.outer.cell(), never adopt into it, and never use its authority.cells to reseed an already retained destination. The current class successor supplies all current cell contents. Nested classes install a new frame and restore the exact previous frame in finally. A newly invoked helper resolver starts with no inherited class frame; its recorded capture bindings provide its own enclosing activation. If/Try/loop traversal within the same class retains the active frame naturally.

## Capture routing and the four guards

At _with_callable_authority 17612-17648, method defaults/decorators still evaluate using the current class namespace. Method-body free destinations resolve through the frame's immediate enclosing nonclass activation. A nested class skips the outer class namespace too. Ordinary local functions resolve through their own immediate activation. No search of an accidental caller or an older ancestor may fill a forwarding hole.

For an existing capture token, use the current successor cell if present and do not copy a value from the frame snapshot. A retained token missing from the current store remains an unresolved retained-store obligation. The only legitimate new capture allocation follows the existing current activation route: local_names already allocated lexical locals; a fallback .cell(name) allocation is unproved and must not upgrade itself based on value kind or nonmissing content. These cases must remain distinct in code.

At _call_environment 14437-14455, incoming bindings start from the invoked callable's capture records, not from a fork's unrelated caller bindings. Preserve required legacy name/global projections separately. Then the callee constructor allocates its own local_names. Apply the same binding rule after _registered_helper_environment seeding. This is why C03's factory is called inside the class after bindings reset: an own-declaration-only fix or accidental caller inheritance must not pass it.

Before any AuthorityState.join record tuple union at 14018, preserve missing/unproved alternative evidence in existing helper_refusal/helper_obligations. Never drop an alternative, merge its cells with a complete alternative, and then infer completeness from the union. Keep compatible record scopes; None or conflict is conservative and cannot be reconstructed from a surviving definition merely to grant relief. Construction of a dormant unresolved callable need not emit a standalone blocker; later consumption must retain the refusal.

Use the same proof decision at all four existing seams:

1. _snapshot_call namespace-effects refusal, 16179-16182: inspect each original callable/capture operand before evidence-losing merge. Proved lexical destination rebinding does not automatically mutate the old owner object.
2. _assign Name guard, 20764-20770: suppress only the unresolved namespace-rebinding treatment for a proved declared nonlocal destination; perform the normal semantic write through its exact binding tuple.
3. _delete_target Name guard, 21124-21130: same proof, preserving existing lookup/raise and unbound marker behavior.
4. _helper_rebound_names and post-call poisoning, 18475-18483: proved lexical writes/deletes must not be added and later overwritten with the generic unknown marker. Unproved/global cases retain the current conservative route.

Keep single-cell strong writes and alternative-cell weak writes unchanged, including deletion. Attribute/subscript/reflection mutation guards and protected owner alias mutation are not relaxed. The original owner-safe expectation is not weakened. A's note enumerates the six cell-key annotation changes and confirms no runtime int arithmetic/order dependence on cell keys; object authority IDs and AST observation/result IDs remain ints.

## Class successor phases and namespace ownership

1. Evaluate decorators, bases and keyword values in the outer namespace, in existing order, using existing expression successor handling and protocol checks. A header throw is already an outer state and is not class-projected. Freeze the frame only after a completed header, retaining header side effects and outer scratch ownership.
2. Fork that outer state for class execution and reset class bindings exactly as today. Run admitted class statements through _flow_statement. Real Raise therefore terminates the normal class sequence, and known always-raising helper exits stay exceptional. An internal class If/Try/finally remains inside this namespace and frame; do not project an exception before an internal handler has had its chance to catch it.
3. Once the class body returns, project each final outward exceptional state separately. Preserve exception_tag, explicit, and excluded_handlers exactly. The projection uses only the outer name/binding skeleton plus that successor's current object/cell authority; class module, method, handler alias and other class-local names do not enter the outer handler. A nested class projects to its enclosing class first, one frame at a time.
4. For each normal body successor, project to the outer namespace, then run existing descriptor/class-decorator completion and bind the class name there. Descriptor inspection still reads the final class namespace. Construction obligations retain the current authority. No class installation or completion protocol runs for an unsuccessful body.
5. Restore frame, exception collector and _current_effect_values in finally at their owning boundaries. Preserve the outer observed/results tables as helper completion already does at 18461-18467. Use a shared adoption/refresh helper where practical, but do not import callee/class scratch into the outer expression. Do not add authority joins solely to move a state: joins clear scratch and can weaken data.

The body driver follows the existing _flow_statements algorithm (21592-21611); the extra class-local work is direct-method metadata collection, not a new exception evaluator. Keep its existing coalescing order and fork behavior. No shortcut transfers ownership of a singleton state or mutates an input wrapper without a complete alias-lifetime proof.

Make _flow_statement_value dispatch ClassDef to this path before generic expression handling (currently 22171-22179). Remove the old independent per-item ClassDef implementation at 22935-23113. Any residual legacy _statements class entry must delegate to the same class successor engine and translate already-projected exceptions exactly once; it must never restore the old loop or flatten raises into normal completion. Audit that bridge's callers explicitly during implementation. Parsed valid class bodies do not return/break/continue out of a class; unexpected synthetic/invalid channels remain conservative rather than being invented as valid outer control flow.

This preserves the existing exception precision boundary. Helper effect completion currently merges normal/return/raised authority at 18457-18464, and only no-normal/no-return helpers surface known always-raise tags at 18489-18496. Class projection cannot reconstruct correlations lost there. C01/C02 use the supported always-raise shape; they do not license a new path-sensitive mixed helper model. TryStar and unresolved protocol exceptions retain their blockers.

## Method metadata without another owner store

Keep a local, class-driver-owned ordered method_authorities list for the existing immediate FunctionDef/AsyncFunctionDef construction obligations. After a reached direct-method statement, collect its installed value from its normal successor(s); retain earlier entries even if a later class statement overwrites that method name. This preserves the existing retention behavior that a final namespace scan would lose. If no normal class successor survives, no class object consumes the list.

Do not put this list in authority.observed or results, since joins clear them. Do not create a synthetic authority owner solely to append this metadata. No fourth auxiliary state is needed for the bounded initial direct-method metadata scope. Existing helper/local-generator definition registries continue their existing auxiliary capture/restore/merge treatment. A method defined under a reached If/Try gets the persistent class frame for capture and ordinary definition registry handling, so its direct call is analyzed correctly.

This does not silently extend descriptor/method-discovery precision for conditionally installed methods. Existing descriptor construction uses direct AST method definitions. Broader conditional descriptor retention would require an explicit separately reviewed scope; a fourth auxiliary component would be conservative may-metadata, not automatically normal-successor-correlated metadata, because current If auxiliary merge includes raised branches. Preserve existing conservative descriptor/metaclass outcomes instead of claiming the new frame solves them.

The helper-disabled prepass retains its direct dormant-method shortcut and dedicated eager construction visitor. Do not let frame lifetime make that prepass install or scan every dormant method body again. The known staticmethod/classmethod/property construction treatment at 22857 must check the active class construction context, not the removed immediate-item override. No broader body expansion or support claim follows.

## Recursive review entry and raw state handling

_snapshot_call already has both matching values and callable operands before helper effects. Publish its merged callable into callable_values_by_call at the same time as values_by_call. Before union, preserve incomplete capture evidence. Do not recover the callable later from a same-spelled name, current mutable state, source AST reevaluation, or observed entries cleared by join.

At recursive _review_body entry 25305-25329, take that historical pair, run the same capture environment builder as effect analysis, raw-remove the child local_names from the entry projection, and pass the resulting state to the existing child resolver/local allocation boundary. Preserve call-site defaults, arguments, module filtering and recursive limits. No replay of transfer, setter effects, or capture allocation is allowed solely to hydrate review input. This lets C11/C12 observe the call-point cell while retaining their actual recursive public-row route, independently of whether the outer projection also became fresh.

All raw installation remains behind the adapter's explicit projection helpers. Do not call dict.__setitem__ on a future non-dict adapter, and do not replace an overlay update with wholesale name replacement. Class exit deliberately starts from the outer snapshot, so it is neither class-name overlay nor adoption of class bindings. Fork/adopt/join carry cell identity/provenance unchanged. Preserve existing key order, first-owner behavior, historical snapshot isolation, and exact raw-versus-semantic write distinction.

## Explicit unresolved edges and finite verification obligations

The twelve cases and earlier ten are a finite regression contract, not a proof of all Python class semantics. Before source approval, keep these distinctions visible:

- Plain class-body Name fallback after a helper changes an enclosing cell is a separate projection question. Class bindings are empty and Name currently reads values.get at 18594-18597. The frame alone cannot tell an inherited fallback from a class-local assignment that happened to store the same FlowValue; identity equality is not a shadowing proof. Do not refresh every class name from outer cells, which would overwrite legitimate class shadows. No new clean support is promised for this uncovered edge. If it falls within the intended repair, freeze a discriminating class-read/shadow schedule and choose explicit class-namespace tracking before implementing that additional behavior.
- Direct class-body global/nonlocal declarations are distinct from method declarations. Do not apply the enclosing function's lexical_scope to prove a class assignment, or call the function-only _lexical_binding_scope on ClassDef (it reads args). The current plan's proved writes are invoked local helper writes through recorded captures. Unsupported direct class declaration/module effects remain conservative pending a separate admitted-contract decision.
- Function/class/comprehension boundaries and eager defaults must be handled by the scope-aware capture discovery in A's plan. Grandparent forwarding is required; arbitrary defining-module/absent-global precision is not. Do not derive proof from any convenient known FlowValue.
- General descriptors, metaclasses, conditional method protocols, TryStar and unsupported AugAssign do not gain clean-support promises. Missing retained-store provenance and mixed capture alternatives stay conservative. C04 remains permitted-refusal, not required-clean.

Charge actual frame forks, outer binding visits, cell-alternative merges, raw projection publication and retained callable snapshots. Reuse existing scope computation, do not rescan a whole dormant body for every guard/write. A's lexical token adds its explicit allocation/reference charges; no cap, reset, refund, unmetered copy or name-storage shortcut is proposed. The current storage corpus-fitness diagnosis is independent; semantic work is not evidence that held storage performance is acceptable.

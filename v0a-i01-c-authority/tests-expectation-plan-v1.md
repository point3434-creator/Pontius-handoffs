Only the owned test file changes. Existing classes, methods, constants, census,
and generated files remain untouched. Add one standalone matrix test class.

The 274-case proposal duplicated positional/receiver binding axes already covered
by the preserved tests. Refine the transfer backbone to default versus live-cell
capture (2 x 8 transfer routes x 4 execution modes = 64), then add named matrices
for the 16 issued A/B witnesses, later cells in both directions, activation reuse,
nested alias/store routes, dictionary extraction before later clear, ordered class
bindings and construction failures, exception/branch successors and dormant versus
consumed deferred work. Planned total is about 182 schedules; exact generated
counts and any exclusions will be recorded. No random sampling or unbounded heap.

Each schedule has an explicit expected harmless result, ordered trace, and public
classification: clean, required refusal, or permitted conservative refusal only
for a stated unsupported effective shape. Sensitive source is passed only as
bytes to derive_design_review. An independently assembled harmless module uses
unittest and local objects only; its sink returns fixed and emits an oracle event.
Oracle-only comment markers insert trace observations, never sensitive operations.
No sensitive-source string is compiled or executed. Never infer mutation merely
from an exception type. A valid RED is an assertion about public semantic output,
not a syntax error, fixture error, budget/identity setup error or test exception.

Expected invariants:
- Dormant storage/return/default capture alone does not execute a callback.
- An admitted readonly call remains lawful; unsupported result precision may
  conservatively refuse only when that allowance is explicit in its case.
- Reached relevant namespace writes require explicit blockers even if a literal
  sentinel capability is still emitted. Dropping rows alone cannot pass.
- Defaults retain their source-point object; cells retain later-binding identity.
- Different factory activations cannot share cells or collections accidentally.
- Alias timing and nesting do not alter a represented object's reached authority.
- Removal extracts a value before later mutation/clear of the container.
- Class method definitions bind before later defaults/decorators; failures do not
  install later definitions or execute later effects.
- Callee lookup precedes arguments, arguments precede binding, and exact proved
  exception successors preserve dead versus reached bodies and finally effects.
- Unknown branches are tested over both harmless valuations; one feasible unsafe
  successor requires refusal. A baseline readonly unknown seam is checked first.

All nine A witnesses and seven B witnesses get named required-refusal cases.
Unsupported absent-global lookup assumptions are excluded. General reflection,
metaclasses, arbitrary heap, ambient mutation and general async support are not
required. Existing finite analyzer limits and old semantic assertions are fixed.

Each matrix emits planned/generated/exercised/unreachable counts plus per-case
source hash, oracle trace/result and actual public rows/blockers. Runtime events
must match independent expected events before an analyzer assertion is counted.
RED execution uses a new frozen-r010 clone with only this test file overlaid,
actual 3.11.15 first then 3.14.6, full pre-import identity and the prescribed
snapshot environment. No replacement source participates in RED. Published
receipts and failed attempts are retained create-only; final released tests and
patch are hashed before root/B snapshot them.

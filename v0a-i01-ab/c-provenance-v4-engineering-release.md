The mechanism now seeds every metered relevant binding load, retains callable definition/default/free-value/receiver authority separately from legacy abstract values, and follows it through modeled argument, return, container, implicit-protocol, and deferred boundaries. The shared bounded call-effect projection distinguishes proved no effect from a relevant unresolved effect; absent free-binding proof no longer means proved absence of an effect. It uses the existing argument binder, source-order successors, namespace refusal rules, and analysis budget. No map/filter/sorted callback interpreter or general heap model was added.

Known native list/tuple/mapping retention preserves callable obligations without invoking a callback or invalidating its owner merely for storage. Known async function creation retains future obligations; the narrow inert-close proof requires a newly created native coroutine, excludes async generators by lexical yield discovery, and is dropped on modeled progress. An arbitrary object member spelled `close` cannot discharge obligations. Implicit dispatch uses the represented callable signature, including property fget, ordinary/staticmethod/classmethod protocols, defaults, and forwarded callable contexts. Literal-only bodies provide a no-effect proof independent of unsupported variadic binding.

Release boundaries:

- Relevant opaque callback/retention/consumption paths retain authority and explicitly refuse when the shared projection cannot prove no relevant effect; they are not newly executed by this analyzer. This can remain conservative for external or lazy APIs. Known native storage and dormant known bodies have paired no-effect controls.
- Unsupported relevant descriptor binding, deferred helper consumption, unresolved namespace-owner effects, recursion/depth exhaustion, and relevant construction/annotation effects refuse. Existing strict budgets remain the limit; no retry budget or CI boundary was enlarged.
- General asynchronous execution, async-generator execution, arbitrary descriptor/decorator/metaclass/class namespace semantics, dynamic annotation evaluation, and a full Python object heap are not implemented. The close proof is not reusable after modeled progress and makes no claim about suspended coroutine close/finally behavior.
- Arbitrary external ambient-state mutation without modeled retained authority, unmodeled extension callbacks, and other Python construction/protocol surfaces not represented by existing admission paths are unclassified by this bounded change. No exhaustive all-Python escape closure or universal external safety claim is made. The named cases and modeled obligation boundary are the release claim.

No known focused contract failure remains.

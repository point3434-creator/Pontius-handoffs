# r001 coverage — failure occurrence and transport

Deferred input: read only after recording an independent invariant/path inventory.
Category: every source occurrence and exception-transfer step across dispatch,
bookkeeping, publication and finalization. Discovery used all Clock* catches,
record/closure/classification producers, context-manager definitions/call sites
and the public source/oracle/writer seams in the six v0a modules.

The first source failure is retained independently of exception propagation.
A later failed read keeps the prior ClockInvalidError refusal API while its exact
internally owned identity maps to the original occurrence. Runtime drains an
unretained source failure before other records or closure observations and before
body/cleanup handling. Both measured owners share one explicit context-manager
class. No caller exception crosses a generator context manager on this path.

Exercised: four added regression methods, 74 subcases: 18 entry/echo/distinct-body
cases, six caught-source return/error/mismatch cases, 48 settlement/publication
error-presentation/metadata/traceback cases with/without genuine cleanup faults,
and two hostile typed source-error cases. Every fixture is exercised. Expected
cause sequences use actual source/body observations, not journal helpers.
Preserved opposing controls: all prior 123 focused tests, including full-clock
sweeps, rejected-input abort order, fresh body faults, returned mismatches,
accepted actions, complete settlement and disjoint terminal publication.

RED: red-v2-311 receipt, r006 production + regression-only overlay, four methods
with 54 failed subcases and no harness error. red-v1 is retained but inadmissible:
the test reporter itself followed the hostile exception context. The correction
moves its assertion outside the except block.
GREEN: freeze-check-311 and freeze-check-314, 127 tests each; both literal executable
versions asserted before imports, floor first, fresh snapshots, scrubbed environment.
An intermediate full suite exposed old dead-read type compatibility; it was restored.
The final implementation also restores unchanged UTF-8 comments accidentally
misdecoded by a Windows-default text read during editing; all final reads use UTF-8.

Limits: no exhaustive higher-order claim; source schedules are deterministic CPU
correctness controls. Unsupported nested intervals, fabricated/foreign failure markers
and private-state mutation are not new requirements. Policy authority/value admission,
strict trace/legal verification and publication/accounting remain separate corrections.
Falsifier: any supported schedule loses, invents or reorders a genuine typed cause,
escapes a required completion receipt, retries a dead source, or loses accepted actions.
